## Problem

Score : 100 points

Problem Statement

You are given a positive integer N.

You will print a document consisting of N pages on sheets of copy paper.

You will use double-sided printing, so one page can be printed on each of the front and back of a sheet.

Find the minimum number of sheets of copy paper needed to print all N pages.

Constraints

- 1\le N\le 100

- N is an integer.

Input

The input is given from Standard Input in the following format:

```
N
```

Output

Print the answer.

Sample Input 1

```
3
```

Sample Output 1

```
2
```

By printing on both sides of one sheet of copy paper and on one side of another, you can print 3 pages using 2 sheets.

Sample Input 2

```
6
```

Sample Output 2

```
3
```

Sample Input 3

```
59
```

Sample Output 3

```
30
```

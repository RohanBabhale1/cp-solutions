Chef has a simple undirected graph $G$ with $N$ vertices and $M$ edges. A [subgraph](https://mathworld.wolfram.com/Subgraph.html) $H$ of $G$ is called *good* if:
- $H$ is connected
- $H$ contains all $N$ vertices of $G$
- There is a unique path between any two vertices in $H$, using only edges in $H$

Count the number of *good* subgraphs of $G$. Since this number might be large, report it modulo $10^9 + 7$.
